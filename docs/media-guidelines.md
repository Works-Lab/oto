# Media Guidelines

Document prototypes before they look polished. The point is to preserve useful evidence from each version.

For each meaningful prototype, capture:

- one top-down photo
- one side photo
- one close-up of the mechanism
- one short video of motion if possible
- prototype version and date in the file name or caption

Good media should make the design easier to inspect later. Do not wait for perfect lighting, finished surfaces, or a clean bench if the prototype is ready to learn from now.
