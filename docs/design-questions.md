# Design Questions

Open questions to answer through prototypes, tests, and documentation:

- What parts should be printed, and what parts should be off-the-shelf?
- How should the pad interface be serviced or replaced?
- How can the mechanism avoid being overbuilt for the actual forces and wear it sees?
- What is the simplest repeatable way to document tests across prototype versions?
- What minimum media is needed before public posts are useful?
- Which printed features are worth refining first: rails, bosses, pad interfaces, chassis geometry, or service access?
- What information should be captured before changing a prototype so comparisons stay meaningful?
